# How a run works

Type: grilling
Status: open
Blocked by:

## Question

What is a single run of the slice?

- How many floors, and how long does a run last in minutes?
- How does a run end: reaching the bottom, a boss, or a time limit?
- What happens on death: roguelite (lose everything and start over) or Diablo-style (the character and gear persist)?
- Does anything carry between runs?

This is the central structural decision. The dungeon layout, the items and the viability test all hang on it.
