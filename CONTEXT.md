# Descent VR

A Diablo-like action RPG for VR in the browser, built as a hobby by one developer. This glossary holds the game's design language.

## Language

**Vertical slice**:
A short, complete, playable descent that tests whether the game is worth continuing.
_Avoid_: demo, MVP

**Viable**:
Worth continuing as the developer's own hobby game, as judged by the developer playing the vertical slice alone.
_Avoid_: shippable, commercial, fun (on its own)
